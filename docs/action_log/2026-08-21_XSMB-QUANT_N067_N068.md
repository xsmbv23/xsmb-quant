## N068 — quorum semantic drift
Audit found that `verification/real_source_quorum_probe.py` independently decided quorum using only distinct `source_id` values. That could allow probe semantics to diverge from the canonical reconciliation gate.

Changed the probe to delegate admission to `data.reconciliation.reconciliation_gate_v1.reconcile(...)`, thereby reusing registry membership, independence groups, observation integrity, conflict handling, and minimum quorum semantics.

- Code commit: `c49a8f69b572699a0eec0d972d25734567e0e585`
- Regression test commit: `4109a804c2fb4a153fa6a45da9f870e946d1312c`
- Latest Render deployment is queued/building; runtime verification remains UNKNOWN until the deployment completes and is independently observed.

## Admission invariants preserved
- FULL_27 is canonical; TAIL_27 remains derived.
- No single source can promote itself.
- PASS is local to its gate.
- No PASS inheritance.
- UNKNOWN is not PASS.
- Candidate evidence is not promotion.
- Promotion remains DENY.
- No synthetic historical data was introduced.
