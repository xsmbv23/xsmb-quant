# Data Foundation Contracts

These contracts are the first executable boundary of the rebuilt system.

1. `full27_v1.json` defines the lossless canonical prize structure.
2. `calendar_v1.md` defines draw-state semantics and prevents missing-data fabrication.
3. `FULL_27` is canonical source truth.
4. `TAIL_27` is derived only after FULL_27 validation.
5. Legacy `Ket_Qua_Loto27.xlsx` is a reconciliation reference, never canonical truth.
6. Promotion remains denied until provenance, calendar, schema, reconciliation and Brain governance gates pass.
